# Notebooks

`carousel_metric_reorganized.ipynb` is the recommended notebook-first workflow.
It is self-contained and does not import functions from `src/carousel_metric/`.
All helpers are defined directly in notebook cells.

`carousel_metric_original.ipynb` is the raw original notebook copied from
Downloads for reference.

The `src/` package remains available as an optional reusable version of the same
logic, but it is not required to run the cleaned notebook.
